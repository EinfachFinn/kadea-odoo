# Kadea Odoo-Module

- Ein Ordner pro Modul, das Repository ist direkt als Odoo-Addons-Pfad nutzbar. Zielversion: Odoo 19.
- Fokus ist Odoo: Funktionen, Begriffe und Bedienung werden auf Odoo und seine Nutzer ausgelegt.
  Keine Kompromisse zugunsten externer Programme (z. B. keine Obsidian-Kompatibilität im Modul `wissensmanagement`).
