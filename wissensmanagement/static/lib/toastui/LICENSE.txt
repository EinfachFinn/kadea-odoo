Toast UI Editor 3.2.2 (MIT) – gebündelt mit ProseMirror (MIT) via esbuild als IIFE (window.toastui.Editor), inkl. de-DE.
ProseMirror ist bewusst auf die ES5-Versionen gepinnt, mit denen Toast UI 3.2.2 gebaut wurde
(state 1.3.4, view 1.23.13, model 1.16.1, transform 1.4.2, commands 1.2.2, history 1.2.0, inputrules 1.1.3, keymap 1.1.5).
Neuere ProseMirror-Versionen verwenden ES6-Klassen; Toast UI erbt davon im ES5-Stil, was z. B. beim Markieren
von Tabellenzellen zu "Class constructor … cannot be invoked without 'new'" führt.
Patch vor dem Build (Toast-UI-Bug, "Cannot read properties of null (reading 'match')" bei Tabellen):
in dist/esm/index.js, Funktion isCustomHTMLInlineNode:  var html = node.literal;  ->  var html = node.literal || '';
Build: package.json mit "overrides" für diese Versionen, Patch anwenden, dann
esbuild entry.js --bundle --minify --format=iife --target=es2020
Zusätzlich enthalten: prosemirror-collab 1.2.2 (MIT) für das Live-Mitschreiben. entry.js stellt
window.toastui.pm = { collab, sendableSteps, receiveTransaction, getVersion, Step, Plugin, PluginKey,
Decoration, DecorationSet } aus denselben ProseMirror-Instanzen bereit, die der Editor nutzt.
