# kadea-odoo

Eigene Odoo-Addons (Odoo 19). Das Repo-Verzeichnis kann direkt als Addons-Pfad
eingebunden werden:

```
addons_path = ...,/pfad/zu/kadea-odoo
```

## Addons

| Addon | Beschreibung |
|---|---|
| [`social_media_instagram`](social_media_instagram/) | Instagram-Connector für OCA `social_media_base`: Posts planen (manuelle Veröffentlichung, kein Upload), Statistiken, Kommentare |
| [`wissensmanagement`](wissensmanagement/) | Wiki direkt in Odoo: Seitenbaum, WYSIWYG-Editor, Vorlagen, Live-Mitschreiben, @-Erwähnungen aller Odoo-Datensätze mit Live-Karten, Papierkorb, Freigaben und Ordnerrechte. Anleitung: [`docs/Anleitung Wissensmanagement.md`](wissensmanagement/docs/Anleitung%20Wissensmanagement.md) |
